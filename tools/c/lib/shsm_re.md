# shsm_re: Python's `re` module

`#include "shsm_re.h"`. Ports the `re` module as the Python tools use it (about 115 tool files, 550 call sites,
585 distinct patterns). Engine: PCRE2 10.44 (8-bit, Unicode, JIT), vendored in `third_party/pcre2/`. A translation
step parses the Python pattern the way CPython's `re._parser` does and rewrites it for PCRE2; the scan loops
(finditer, findall, split, sub) are written here with Python's empty-match rules. The header documents every
function; this file is the overview.

Provenance: `shsm_re.c`, `shsm_re_translate.c`, `shsm_re_priv.h`, `shsm_re.h` and `tests/shsm_re_test.c` are
The other project's `core/src/re.c`, `core/src/re_translate.c`, `core/src/re_priv.h`, `core/include/avp/re.h` and
`core/tests/re_test.c` at commit `49e811503d7ba5c9cff92160557df057c50a8ab3`, with the names `avp_re*` / `AvpRe*` /
`AVP_RE_*` renamed `shsm_re*` / `ShsmRe*` / `SHSM_RE_*` (and the private `re_translate`, `re_trans_free`,
`re_format_error`, `ReTrans` prefixed `shsm_`); no other change. The test's corpus is this project's.

| Python | C |
|---|---|
| `re.compile(p, flags)` (literal, known valid) | `shsm_re(p, flags)` (cached process-wide; an invalid pattern panics) |
| `re.compile(p)` of a run-time pattern (`--select`, `% normalize:`) | `shsm_re_try(p, flags)` / `shsm_re_try_n` (throws `AVP_ERR_REGEX` with `str(re.error)`), `shsm_re_compile` (no throw) |
| `re.I`, `re.M`, `re.S`, `re.X`, `re.A`, bytes patterns | `SHSM_RE_I`, `_M`, `_S`, `_X`, `_A` (Python's values), `SHSM_RE_BYTES` |
| `p.search` / `match` / `fullmatch(s, pos, endpos)` | `shsm_re_search` / `_match` / `_fullmatch(re, s, pos, endpos, &m)` (`0, AVP_END` for the whole string) |
| `m.group(g)`, `m.group(name)`, `m.span/start/end`, `m.lastindex`, `m.lastgroup`, `m.expand` | `shsm_re_group`, `shsm_re_group_named`, `shsm_re_start` / `_end` / `_matched`, `m.lastindex`, `shsm_re_lastgroup`, `shsm_re_expand` |
| `p.groups`, `p.groupindex`, `p.pattern`, `p.flags` | `shsm_re_groups`, `shsm_re_group_index` / `_group_name`, `shsm_re_pattern`, `shsm_re_flags` |
| `p.finditer(s)` | `ShsmReIter it; shsm_re_iter_init(...); while (shsm_re_iter_next(&it, &m))` |
| `p.findall(s)` (str / group / tuple shapes) | `shsm_re_findall` + `shsm_re_findall_at(r, i, j)`, `.width`, `.count`; `shsm_re_findall_free` |
| `p.split(s, maxsplit)` (groups included, `None` = `.p == NULL`) | `shsm_re_split` |
| `p.sub` / `p.subn(repl, s, count)` with `\1`, `\g<name>` templates | `shsm_re_sub` / `shsm_re_subn` |
| `p.sub(callable, s)` | `shsm_re_sub_fn(a, re, fn, ctx, s, count, &n)` |
| `re.escape(s)` | `shsm_re_escape` |

Offsets are byte offsets in the UTF-8 subject (Python's are code points; convert with `avp_u8_len` on the prefix
when printing one). A str subject must be valid UTF-8 (`AVP_ERR_FORMAT` otherwise).

Python semantics kept where PCRE2 differs (by the translation): `$` before a trailing newline, `\Z` (PCRE2 `\z`),
`{,n}` and literal `{`, Unicode `\w \d \s \b` as Python defines them (PCRE2's are wider), `.` and DOTALL, VERBOSE
(also scoped), scoped inline flags, `\xhh`, `\uXXXX`, octal escapes vs group references, `(?P<name>)`, `(?P=name)`,
conditionals, atomic groups and possessive quantifiers, `[` literal in a class, Python's re.error messages for
syntax PCRE2 accepts and Python rejects, empty matches in `sub`, `split`, `findall` and `finditer` (3.7+ rules).
What is not reproduced is in `shsm_re.DEVIATIONS.md`.

## Tests

`tests/shsm_re_test.c` (CTest `shsm_re_test`, label `lib`):
- about 300 hand-picked cases of the Python/PCRE2 differences, with CPython's results (from that project);
- `corpus_all_patterns`: the golden corpus `tests/shsm_re_corpus.h`, generated by
  `tests/gen_shsm_re_corpus.py` from this repository: every pattern the Python tools use (static literals and
  module constants found with `ast`, run-time patterns instantiated with placeholders, and the hand-instantiated
  run-time patterns of `tests/shsm_re_extra.txt`, extracted file by file from the tools' source), run by CPython
  over a sample text made of repository lines (symbols.txt, splits.txt, the retail listings, sources, docs,
  build files) plus probes: per probe search / match / fullmatch spans and lastindex; over the whole sample
  finditer spans (hash), findall and split (hash), and subn with the tools' own templates plus generic ones. The
  corpus holds 585 patterns, 3,385 probes and 1,508 sub runs (13,418 compared results); every one is identical.

The corpus was generated with the retired generator `tools/c/tests/gen_shsm_re_corpus.py` (removed with the Python tools; the corpus header and `shsm_re_extra.txt` are now maintained by hand). Its commands were:

    python tools/c/tests/gen_shsm_re_corpus.py . tools/c/tests/shsm_re_corpus.h
    SHSM_RE_DYNAMIC=<file> SHSM_RE_LIST_ONLY=1 python tools/c/tests/gen_shsm_re_corpus.py . x   # run-time sites to instantiate in shsm_re_extra.txt
