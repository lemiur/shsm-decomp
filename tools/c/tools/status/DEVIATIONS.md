# status: accepted differences from tools/status.py

Proven equal to the retired Python tools/status.py by the differential harness, removed at retirement, commit 66ee84d3. Last run: 513 cases, 513 same; 21 chart cases, 21 same.

Format: README.md, "Deviations".

## D-status-1. The rule checker runs in-process
- Behaviour: for the headline without `--no-checker` or `--checker-json`, status.exe runs the C rule checker
  in-process (`tool_check_rules`: `check_rules --json --root <root>`) and reads the run as ledger.exe does
  (`rl_checker_json_of`): its failures give the notes `rule checker unavailable (rule checker failed (exit N): ...)`
  and `... printed no JSON: ...`.
- Reason: the C tools link each other rather than shell out; ledger, pick and status share the one reading of the
  checker's run, so they agree on its output.

## D-status-2. Non-ASCII digits in the docs/progress.md numbers block
- Behaviour: `ledger_block` reads the block's numbers with the same pattern (`\d+`, Unicode digits as Python's `re`
  matches them through shsm_re), but converts each with `avp_parse_int`, which reads ASCII digits only; a number
  written in other Unicode decimal digits (Python's `int()` accepts them), or one above 64 bits, reads as 0.
- Reason: the block is generated by tools/ledger.py with ASCII digits only and stays far below 64 bits; such a block
  cannot occur short of a hand edit, and the comparison against the computed numbers would still print it as
  different.

## Notes (not deviations)
- tools/c/tools/ledger keeps `read_text`, `load_json` and `run_checker` static in `ledger_cli.c`; status has its own
  copies of the three (status.c, the same behaviour as the Python's `ledger.read_text`, `ledger.load_json` and
  `ledger.run_checker`) and links ledger's model (`ledger_parse_configure`, `ledger_parse_exceptions`,
  `ledger_build_model`). The Python's uncaught `AttributeError` for a report or checker document that is not a JSON
  object (`'list' object has no attribute 'get'`) is raised with the same text before the model is built.
